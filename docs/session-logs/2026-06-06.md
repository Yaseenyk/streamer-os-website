## 1. Technical documentation hub at `/docs`

**Goal:** an industry-standard docs hub. Original plan was Nextra.

**Key finding — Nextra is a dead end on Next 16 (this repo's version):**
- **Nextra 3.3.1** — fails at *compile* time. Its search plugin calls `pkg.init()` on `next/dist/compiled/webpack/webpack.js`, a private internal that Next 16 removed (`typeof init === 'undefined'`). Throws at module-import time, so `--webpack` can't avoid it.
- **Nextra 4.6.1** — compiles fine on Turbopack but every MDX page 500s at render/static-export with an internal Zod error: `Invalid input: expected nonoptional, received undefined → at children`. Systemic (even a one-line page fails), not content-related. A Nextra-vs-Next-16 incompat only Nextra can fix.
- All verified in a throwaway scratch dir (`D:\nextra-scratch`, since deleted), never touching the repo.

**Decision:** pivoted to a **native `@next/mdx` App Router docs hub** — first-party, versioned with Next, no private-API coupling. Verified the full stack (output:export + Turbopack + remark-gfm + rehype-slug + rehype-autolink-headings + @tailwindcss/typography) builds + statically exports on Next 16 before touching the repo.

**Shipped (commit `33dd0b1`):**
- `next.config.ts` — wrapped with `createMDX`, added `pageExtensions`; preserved `output:'export'`, `basePath`, `images.unoptimized`. Plugins passed as **strings/serializable tuples** (Turbopack requirement on Next 16).
- `app/globals.css` — added `@plugin "@tailwindcss/typography"`.
- `mdx-components.tsx` (root, required by App Router).
- `app/docs/{_nav.ts, layout.tsx, page.mdx, installation/page.mdx}` — sidebar shell (cyan active state) + Introduction + Installation. Docs inherit the site Header/Footer via the root layout (more integrated than Nextra's isolated theme).

## 3. Blog index UX — `InteractiveBlogGrid` (commits `2fdcbc6`, `bdb1f47`)

Server/client split: `app/blog/page.tsx` stays a Server Component reading frontmatter at build time (`getAllPostMeta`), passing serializable `PostMeta[]` to a new `"use client"` island.

- **`2fdcbc6`** — initial grid: search (title+description), category pills, newest/oldest sort, empty state. Dropped per-card `Reveal` to avoid re-animating on every keystroke.
- **`bdb1f47`** (rolled up several iterations):
  - **Framer Motion** filtering — `motion.div layout` grid + `AnimatePresence mode="popLayout"`; cards glide/fade instead of snapping. Empty state moved into its own `AnimatePresence` so card exit-animations survive the last filter step.
  - **Pill scroll UI** — replaced clipping `pr-8` with an unsquashable `after:` flex spacer; **dynamic JS-driven edge masks** (`useRef` + scroll listener + `ResizeObserver` → `canScrollLeft`/`canScrollRight`) so the fade only shows on the scrollable side and the last pill renders 100% opaque at the end. Mask built in JS/inline-style to avoid Tailwind `calc()` escaping issues.
  - **Curated categories** — replaced dynamic tag extraction (was surfacing junk like "Cybersecurity") with a fixed `CATEGORIES = ['All','Engineering','Guides','Performance','Local AI','OBS Studio']`; filter is case-insensitive exact match.
