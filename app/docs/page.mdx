# streamerOS Technical Documentation

Welcome to the technical documentation for **streamerOS** — the Rust-powered,
ultra-lightweight desktop cockpit for Twitch & YouTube streamers, built as a
companion to OBS Studio.

These docs cover installation, configuration, and the internals of the
Auto-Hype Director engine. For product information and downloads, head back to
the [main site](/).

## What you'll find here

- **[Installation](/docs/installation)** — system requirements and a quick-start guide,
  including how to enable the OBS WebSocket server that streamerOS connects to.
- More guides are on the way.
