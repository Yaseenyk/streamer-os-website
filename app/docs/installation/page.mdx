# Installation

> 🚧 Quick-start placeholder — the full guide is coming soon.

## Requirements

- Windows 10 or 11 (64-bit)
- 16 GB RAM, 8-core CPU
- RTX 3060-class GPU (for local AI features)

## Quick start

1. Download the latest `v1.0-GA` release.
2. Run the installer — no account required.
3. Connect OBS via WebSocket v5 and launch the Auto-Hype Director.
