# Installation

streamerOS installs in minutes and connects to OBS Studio over **OBS WebSocket
v5** — the official control interface that ships inside OBS. There is no
account, no plugin, and no cloud service in the loop.

> 📅 streamerOS v1.0-GA launches **September 2026** for Windows.
> [Pre-register on the download page](/download) to get the release the day it ships.

## System requirements

- **OS:** Windows 10 or 11 (64-bit)
- **Memory:** 16 GB RAM
- **CPU:** 8 cores — the streamerOS core itself holds a
  [1.8% CPU footprint](/features/performance); the headroom is for your game, OBS, and the optional local AI
- **GPU:** RTX 3060-class (only needed for the local AI features)
- **OBS Studio** with its built-in WebSocket server (see step 1 below)

## Quick start

### 1. Enable the WebSocket server in OBS

In OBS Studio, open **Tools → WebSocket Server Settings** and enable the
server. This is OBS's own control interface — streamerOS talks to it over your
local machine only, so there are no third-party plugins to install.

### 2. Install streamerOS

Download the latest `v1.0-GA` release and run the installer. No account is
required — the app is fully functional the moment it opens.

### 3. Connect to OBS

Launch streamerOS while OBS is running. The [OBS Bridge](/features/obs-bridge)
auto-discovers your OBS instance, loads your scenes, and you can switch the
program feed from the cockpit immediately.

### 4. Optional: local AI via Ollama

The AI features (AI Sidekick, chat sentiment) run on a local
[Ollama](https://ollama.com) install — nothing is sent to a cloud model. Skip
this step if you only want automation and telemetry.

## Where to go next

Build your first automation with the
